---
title: "Work"
description: "Pay for an x402 resource with a provider-issued proof-of-work solution."
---

The `work` scheme prices a request in expected proof evaluations. A profile
defines its native job, proof, solution, and source submission. Settlement
succeeds only when that source accepts the solution.

### Server Setup

Register `WorkServerScheme` with a profile issuer, then price the route with an
explicit hash amount and profile. Native source credentials remain private.

### Client Setup

Register `WorkClientScheme` with a solver for each accepted profile. Solvers
receive the job, derived target, and deadline `AbortSignal`.

### Facilitator Setup

Register `WorkFacilitatorScheme` with verifier profiles and a durable shared
replay store. Verification never submits. Settlement re-verifies and submits
the exact solution; an uncredited transport acknowledgement is not payment.
